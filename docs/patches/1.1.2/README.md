При откате/повторном обновлении все **24 137 строк posts** и настройки виджетов сохранены, БД не восстанавливалась.

Дополнительно проверены три темы × четыре режима оптимизации/кеша × три движка: **144** page/viewport результата на кандидате и столько же после отката. Autoptimize действительно обрабатывает JS; WP Super Cache отдаёт подтверждённые HIT. После изменения block widget WP Super Cache требует очистки page cache — это независимо воспроизведено чистым Core Paragraph при выключенном плагине часов. При сохранении записей автоматическая инвалидация работает.

Покрытие ограничено перечисленной матрицей. Публичная доставка WordPress.org и сайт автора отзыва не проверены. Native HTTPS/Site Domains проверен отдельно: обновление, реальные Save, откат, повторное обновление, обычная TLS-валидация в Chromium/WebKit и фронтенд Safari. Его конкретная причина жалобы остаётся неизвестной. Редактирование под возвращённым 1.1.1 снова подвержено прежнему дефекту старой версии.
