## Воспроизведение и исправление

Перед изменением продукта независимый набор `review2-entities.mjs` повторно запущен на прежнем ZIP `1ce5d1d1…`. Результат — **165/168**: три проверки одного случая Author / WP 6.3.2 не прошли. Сохранение подписи `&apos; <clock>` меняло её HTML-значение и делало блок невалидным. Входные fixtures оригинального сериализатора 1.1.1 и ожидаемые DOM-значения оставлены прежними.

Причина — HTML 4.01 декодер атрибутов в WordPress 6.3. Он оставляет `&apos;` строкой, после чего повторное строгое экранирование превращает её в `&amp;apos;`. JSON сохранялся, но HTML-семантика менялась.

В [includes/simple-digital-clock-kses.php](../../../wordpress/simple-digital-clock/includes/simple-digital-clock-kses.php) добавлено небольшое расширение штатного `WP_HTML_Tag_Processor`. Нативный lexer определяет точный исходный диапазон атрибута `caption`; в нём экранируются только буквальные `<` и `>`. Значение не декодируется и не кодируется целиком. Поэтому `&apos;`, `&amp;apos;` и дополнительные слои `&amp;` сохраняют исходный смысл. Удалён временный глобальный фильтр `attribute_escape`.

Используются protected-поля `html` и `lexical_updates`, которые документация установленного WordPress предусматривает для расширений Tag Processor. Учтено различие диапазонов WP 6.3 (`start/end`) и WP 6.5+ (`start/length`). Проверены 1001 отложенная замена, UTF-8, регистр и пробелы атрибутов, одинарные кавычки, пустые атрибуты, комментарии и похожие строки в чужом HTML/script. Реальные event-атрибуты по-прежнему удаляются KSES; HTML-подобная подпись остаётся текстом.

Относительно `1ce5d1d1…` изменён **один файл продукта**. Полный патч к официальному 1.1.1 затрагивает четыре файла: `block.js`, новый `includes/simple-digital-clock-kses.php`, `widget_init.php` и `readme.txt`. Остальные 11 исходных файлов и standalone-виджет 0.7.0 неизменны. Прежние исправления JSON соседних блоков и исходной JSON-подписи сохранены.

## Границы вывода и откат

В проверенной матрице новых регрессий не обнаружено. Нативный LocalWP, multisite, runtime PHP 7.x/8.5 и конкретные сторонние плагины/темы не проверялись. Объектные атрибуты проверены на синтетическом стороннем блоке. При изменениях HTML API WordPress следует повторять эти контракты, поскольку расширение использует protected-диапазоны нативного lexer.

Для проверенного цикла откат выполняется заменой ZIP на официальный 1.1.1 без восстановления записей из backup. Его исходные ошибки редактирования при этом возвращаются. Патч не восстанавливает автоматически ранее потерянную разметку и не ремонтирует созданные красными тестами невалидные записи; приёмка выполнена на свежих валидных записях 1.1.1.

Причина исходного пользовательского отзыва LocalWP остаётся неизвестной. Этот P2 не выдаётся за её объяснение.

Публикаций, Git commit/push, изменений SVN и пользовательских сайтов нет. Только контейнеры и сеть этой лаборатории остановлены через Compose; локальные файлы, БД и доказательства сохранены.
