Independent acceptance found two gaps: the fixed element allowlist removes
native global attributes such as `id`, and Core's dynamically initialized Text
widget bypasses both PHP initialization filters. The `id` loss is a real
compatibility defect: standalone integrations can address clocks by ID. RC10
is retained as an immutable rejected intermediate candidate, not a release.
[RC11](RC11.md) supersedes it with additive schema rules and Core's dynamic
editor event. The original failures remain in the RC10 evidence.

additional native Classic-block tests demonstrated the lost ID. Those scoped
passes do not override the incomplete HTML preservation verdict. Earlier claims
that the ID was unsupported were explicitly withdrawn.
