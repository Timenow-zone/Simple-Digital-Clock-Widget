# WordPress 1.1.6 RC11 candidate

Status: **FROZEN; SUPERSEDED BY RC12; ACCEPTANCE INCOMPLETE; NOT PUBLISHED**.

Plugin Check reported one `WordPress.WP.EnqueuedResourceParameters.MissingVersion`
warning for a null enqueue version, although the supplied URL already had an
mtime query parameter. [RC12](RC12.md) passes that same version through the
standard WordPress parameter. The RC11 ZIP and manifest are preserved; its
partial execution evidence is not transferred to RC12 and is not full acceptance.

RC11 addresses the inherited [Classic Editor HTML-loss defect](../../defects/CLASSIC-HTML-P1-01.md).
It preserves empty clock elements and their containers, the runtime settings,
and native HTML attributes such as `id`. It covers normal and teeny editors,
Gutenberg Classic blocks, and Core's dynamically initialized Text widgets.

The editor helper extends the existing clock schema without replacing its
native attribute definitions or changing foreign span elements. WordPress's
server KSES policy and role permissions remain unchanged. The same helper uses
Core's initialization event for dynamic editors. No public runtime is added to
the editing document by this fix, and ordinary frontend pages do not load the
editor helper.
